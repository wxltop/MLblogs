70.爬楼梯

题目链接：70. 爬楼梯 - 力扣（LeetCode）open in new window

难度：简单

时间复杂度：O(n)

空间复杂度：O(n)

先考虑dp数组的含义，然后考虑状态转移如何表示。dp[i]表示到达i阶一共有几种方法，那么dp[i] = dp[i-1] + dp[i-2]

class Solution:
    def climbStairs(self, n: int) -> int:
        if n < 3:
            return n
        helper = [0] * (n+1)
        helper[1] = 1
        helper[2] = 2

        for i in range(3, n + 1):
            helper[i] = helper[i-1] + helper[i-2]
        return helper[n]

当然由于这里后一个结果仅仅使用到了前两个结果，所以可以使用双指针来将空间复杂度降为O(1)

746. 使用最小花费爬楼梯

题目链接： 746. 使用最小花费爬楼梯open in new window

难度：简单

时间复杂度：O(n)

空间复杂度：O(n)

helper[i]的含义可以表示为：到达该层需要的最小代价，则状态转移公式可以表示为：

helper[i]=min(helper[i−1]+cost[i−1],helper[i−2]+cost[i−2])
class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:
        # helper[i] = min(helper[i-1] + cost[i-1], helper[i-2] + cost[i-2])
        helper = [float('inf')] * (len(cost) + 1)
        helper[0] = 0
        helper[1] = 0
        for i in range(2, len(cost) + 1):
            helper[i] = min(helper[i-1] + cost[i-1], helper[i-2] + cost[i-2])
        return helper[-1]

需要注意的是，从题目描述来看，到达第一层和第二层的代价=0.

同样，可以使用双指针降低空间复杂度：

class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:
        p = 0
        q = 0
        for i in range(2, len(cost) + 1):
            tmp = min(p + cost[i-2], q + cost[i-1])
            p = q
            q = tmp
        return q

当然如果在面试中，能写出版本一就行，除非面试官额外要求 空间复杂度，那么再去思考版本二，因为版本二还是有点绕。版本一才是正常思路。

62.不同路径

题目链接：62. 不同路径 - 力扣（LeetCode）open in new window

难度：中等

1.回溯

回溯超时

class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        self.ans = 0
        def backtrack(i, j):
            if i >= m or j >= n:
                return
            if i == m-1 and j == n-1:
                self.ans += 1
            backtrack(i + 1, j)
            backtrack(i, j + 1)
        backtrack(0, 0)
        return self.ans

来分析一下时间复杂度，这个深搜的算法，其实就是要遍历整个二叉树。

这棵树的深度其实就是m+n-1（深度按从1开始计算）。

那二叉树的节点个数就是 2(m+n−1)−1。可以理解深搜的算法就是遍历了整个满二叉树（其实没有遍历整个满二叉树，只是近似而已）

所以上面深搜代码的时间复杂度为O(2(m+n−1)−1)，可以看出，这是指数级别的时间复杂度，是非常大的。

2. 动归

时间复杂度：O(nm)

空间复杂度：O(nm)

先确定dp的含义：可以将dp定义为一个二维数组，然后dp[i][j]表示，到达(i,j)位置的路径总数。由于机器人只能右移和下移，所以可以得到状态转移公式：

dp[i][j]=dp[i−1][j]+dp[i][j−1]

初始化的时候需要注意，因为遍历数组的时候是从左到右从上到下遍历，而从转移公式中可以发现，更新dp[i][j]前，其上方和左方的值需要确定，所以需要将第0行和第0列的数值全部初始化为1.

class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        if m < 2 or n < 2:
            return 1
        helper = [[0] * n for _ in range(m)]
        helper[0][0] = 1
        for i in range(m):
            helper[i][0] = 1
        for i in range(n):
            helper[0][i] = 1
        # helper[i][j] = helper[i-1][j] + helper[i][j-1]
        for i in range(1, m):
            for j in range(1, n):
                helper[i][j] = helper[i-1][j] + helper[i][j-1]

        return helper[-1][-1]

将空间复杂度降为O(n)：

class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        if m < 2 or n < 2:
            return 1
        helper = [1] * n
        for i in range(1, m):
            for j in range(1, n):
                helper[j] = helper[j-1] + helper[j]

        return helper[-1]

3. 组合

无论怎么走，走到终点都需要 m + n - 2 步。其中往下一定走了m-1步，往右一定走了n-1步，至于哪些步骤往下，哪些步骤往右，都有可能。所以就转化为了：m + n - 2个不同的数，随便取m - 1个数，有几种取法。

时间复杂度：O(m)

空间复杂度：O(1)

求组合的时候，要防止两个int相乘溢出！ 所以不能把算式的分子都算出来，分母都算出来再做除法。需要在计算分子的时候，不断除以分母，代码如下：

class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        numerator = 1  # 分子
        denominator = m - 1  # 分母
        count = m - 1  # 计数器，表示剩余需要计算的乘积项个数
        t = m + n - 2  # 初始乘积项
        while count > 0:
            numerator *= t  # 计算乘积项的分子部分
            t -= 1  # 递减乘积项
            while denominator != 0 and numerator % denominator == 0:
                numerator //= denominator  # 约简分子
                denominator -= 1  # 递减分母
            count -= 1  # 计数器减1，继续下一项的计算
        return numerator  # 返回最终的唯一路径数

63. 不同路径2

题目链接：63. 不同路径 II - 力扣（LeetCode）open in new window

难度：中等

1. 动归

时间复杂度：O(m+n)

空间复杂度：O(m+n)

其实思路和上一题一样，只是在其基础上添加了一些限制条件，情况还挺多，具体如下：

  • 当矩阵只有一行或者一列时，若有遮挡，则返回0，否则返回1

  • 若起点就被挡住，返回0

  • 初始化时，不能按原来的将第一行和第一列赋值1，可以先循环为第一行和第一列赋值，当遇到遮挡时，跳出，因为第一行和第一列后续的位置不可达

  • 正式求helper各项值时，假设要求的是helper[i][j]，若此处是遮挡物体，赋值0；若此处的左边和上边都被遮挡，赋值0；若此处左边被遮挡，helper[i][j]=helper[i-1][j]；若此处上面被遮挡，则helper[i][j]=helper[i][j-1]；若上面和左边都没被挡住，则等于左边和上面值之和

class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        m = len(obstacleGrid)
        n = len(obstacleGrid[0])
        if m == 1 or n == 1:  # 只有一行或一列时
            occ = False
            for i in range(m):
                for j in range(n):
                    if obstacleGrid[i][j] == 1:
                        occ = True
            if occ:  # 有遮挡返回0
                return 0
            else:  # 无遮挡返回1
                return 1
        if obstacleGrid[0][0] == 1:  # 起点就被挡住了
            return 0

        # 初始化
        helper = [[0] * n for _ in range(m)]
        for i in range(m):
            if obstacleGrid[i][0] == 1:  # 遇到遮挡停止赋值
                break
            helper[i][0] = 1
        for i in range(n):
            if obstacleGrid[0][i] == 1:  # 遇到遮挡停止赋值
                break
            helper[0][i] = 1

        for i in range(1, m):
            for j in range(1, n):
                if obstacleGrid[i][j] == 1:  # 本身就是遮挡物
                    continue
                if obstacleGrid[i-1][j] == 1 and obstacleGrid[i][j-1] == 1: #上面和左边都挡住
                    continue
                elif obstacleGrid[i-1][j] == 1:  # 上面挡住
                    helper[i][j] = helper[i][j-1]
                elif obstacleGrid[i][j-1] == 1:  # 左边挡住
                    helper[i][j] = helper[i-1][j]
                else:  # 没有挡住
                    helper[i][j] = helper[i-1][j] + helper[i][j-1]
        return helper[-1][-1]

其实为helper赋值时不用这么麻烦，细分析会发现，除了本身就是遮挡物外，其他的情况直接表示为：也是正确的，虽说逻辑上按照上面写的会清晰一些，但是结果是对的，因为遮挡部分的helper值为0。所以可以将这部分代码简化为：

for i in range(1, m):
    for j in range(1, n):
        if obstacleGrid[i][j] != 1:
            helper[i][j] = helper[i-1][j] + helper[i][j-1]
return helper[-1][-1]

将空间复杂度降为O(n)：

有几个地方需要注意，第一个是初始化，还是一样，若起点遮挡，返回0，若其他地方遮挡，停止赋值。正式遍历时，dp[0]需要额外注意，若第一列中有一个遮挡物，则dp[0]后续都要是0，否则都是1，所以遮挡物带来dp[0]的改变。然后就是[i,j]处为遮挡物时，要显示的将dp[j]=0，不能不做处理，若不做处理会导致下一行的值变大。

class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        m = len(obstacleGrid)
        n = len(obstacleGrid[0])
        dp = [0] * n
        if obstacleGrid[0][0] == 1:
            return 0
        # init dp
        for i in range(len(dp)):
            if obstacleGrid[0][i] == 1:
                break
            dp[i] = 1

        for i in range(1, m):
            if obstacleGrid[i][0] == 1:
                dp[0] = 0
            for j in range(1, n):
                if obstacleGrid[i][j] != 1:
                    dp[j] += dp[j-1]
                else:
                    dp[j] = 0
        return dp[-1]

343. 整数拆分

题目链接：343. 整数拆分 - 力扣（LeetCode）open in new window

难度：中等

1. 动归

先确定dp的含义，前面的题都是从结果往细节去考虑，即要得到dp[i]该怎么做（要跳到这层楼梯，前两步该如何跳？）本题这样考虑的话不容易想通，需要从细节往结果去考虑：

假设已经得到了dp[i]的值，其含义是输入i时，最大乘积值。那么就容易基于这个值可以得到t∗dp[i]，但是注意dp[i+t]不一定等于t∗dp[i]，需要取本身与其的最大值：max(dp[i+t],t∗dp[i])。

但是实际上这样无法通过，因为将n分为两个数相乘和分为多个数相乘需要分开讨论，二者是不包含的，即应该是：max(dp[i+t],t∗i,t∗dp[i])，这里dp[i]是不包含i的，因为如果包含了i本身，说明将i分解为了i和0两个数，题目要求分解为正整数之和。

这样要计算dp[i+t]得将所有的dp值（0~i+t）都计算出来，这样空间复杂度为O(n)。

对于计算dp[k]，数k有很多种分解方法，即k=l+(k−l)，其中l∈[0,k−1]，则需要计算所有的dp[k−l]，k∈[0,n]，所以时间复杂度为O(n2)。

dp的初始化：因为要分解为多个正整数之和，而0和1无法分解，所以初始化为0。

class Solution:
    def integerBreak(self, n: int) -> int:
        dp = [0] * (n+1)
        for i in range(2, n + 1):
            for j in range(1, i):
                dp[i] = max(dp[i], j*(i-j), j * dp[i - j])
        return dp[n]

2. 贪心

本题也可以用贪心，每次拆成n个3，如果剩下是4，则保留4，然后相乘，但是这个结论需要数学证明其合理性！

if n == 4单独拿出来是因为，不满足这个结论。

class Solution:
    def integerBreak(self, n: int) -> int:
        if n == 2:
            return 1
        if n == 3:
            return 2
        if n == 4:
            return 4
        res = 1
        while n > 4:
            res *= 3
            n -= 3
        res *= n
        return res

96. 不同的二叉搜索树

题目链接：96. 不同的二叉搜索树open in new window

难度：中等

1. 动归

时间复杂度：O(n2)

空间复杂度：O(n)

从官方这个例子n=3时去找规律：

n=1，n=2时可以穷举出来，n=3时，当根节点分别为1,2,3时，分别求出结果，然后将各个结果相加即可。而任意一个节点i作为根节点时，都可以将序列分为两个部分，小于该节点值的子序列作为左子树，大于该节点值的子序列作为右子树，其中左子树和右子树的节点个数一定小于n。假设根节点值为i，左子树有nl个节点，右子树有nr个节点，则该二叉搜索树有dp[nl]∗dp[nr]种，这就用到了之前求得的结果dp[nl],dp[nr]，换句话说，现在的结果受之前的结果影响，这样可以用动态规划来解题。

上面分析了对于给定一个n，任意一个节点i作为根节点时的二叉搜索树个数，然而任意一个节点都可以作为根节点，那么将所有的节点都遍历一遍即可：

class Solution:
    def numTrees(self, n: int) -> int:
        if n == 1: return 1
        if n == 2: return 2
        dp = [0] * (n+1)
        dp[1] = 1
        dp[2] = 2
        for i in range(3, n + 1):  # 1~n-1个节点时的结果会被dp[n]用到
            for j in range(1, i + 1):  # 任意一个节点当根节点
                left = j - 1 if j - 1 != 0 else 1  # 左子树节点个数
                right = i - j if i - j != 0 else 1  # 右子树节点个数
                dp[i] += dp[left] * dp[right]
        return dp[-1]

198.打家劫舍

方法1：回溯1

时间复杂度：O(n)，空间复杂度：O(n)。

回溯的思路要确定回溯函数的输入的含义以及函数要完成的功能。这里实现的是：给定i值，判断若数值列表为nums[i: ]，最优解为多少。核心的思路是：利用当前的选择去改变未来的选择（若抢了b房间，则只能间隔一个房间，在b+2抢，不能抢b+1）。那为什么要有一个for循环呢？因为若没有for循环，backtrack(b+2) + self.nums[b]实现的是选择nums[b]的结果，但是还有情况是不选择nums[b]，这种情况的结果没有表示出来，所以干脆用一个for循环来遍历所有的选择情况：若选择这个房间会怎么样。

仅仅这样实现会超时，所以添加一个@lru_cache。

class Solution:
    def rob(self, nums) -> int:
        self.nums = nums
        @lru_cache
        def backtrack(i):
            amount = 0
            for b in range(i, len(self.nums)):
                amount = max(amount, backtrack(b+2) + self.nums[b])
            return amount 

        return backtrack(0)

这种思路有点不合常理，所以下面有了第二种实现方式。

方法2：回溯2

这种方法就更容易理解，将选、不选nums[i]两种情况的结果算出来，取最大值。

class Solution:
    def rob(self, nums) -> int:
        # 1. 回溯：
        self.nums = nums
        @lru_cache
        def backtrack(i):
            if i < 0: return 0
            if i == 0: return nums[0]

            no = backtrack(i-1)
            yes = backtrack(i-2) + self.nums[i]
            return max(no, yes)

        return backtrack(len(nums) - 1)

方法3：动归

先确定dp[i]的含义：只从nums[: i]取值，最优解。题目就化成了：已知dp[: i]的结果，求dp[i]，由于题目的不相邻限制，所以状态转移方程为：

dp[i]=max(dp[i−1],dp[i−2])
class Solution {
public:
    int rob(vector<int>& nums) {
        if (nums.size() == 0) return 0;
        if (nums.size() == 1) return nums[0]; 
        vector<int> dp(nums.size(), 0);
        dp[0] = nums[0];
        dp[1] = max(dp[0], nums[1]);
        for (int i=2; i < nums.size(); i++){
            dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
        }
        return dp[nums.size() - 1];
    }
};

在代码随想录里看到一种二维dp的解法，既然每一个房间有两个状态：抢还是不抢，那就直接点，显示的将两种情况下的最优值给算出来，即dp[i][0]和dp[i][1]分别表示不抢i号房屋和抢i号房屋的最优值。

class Solution:
    def rob(self, nums) -> int:
        dp = [[0, 0] for i in range(len(nums))]
        dp[0][1] = nums[0]
        for i in range(1, len(nums)):
            dp[i][0] = max(dp[i-1][0], dp[i-1][1])
            dp[i][1] = max(dp[i-1][0] + nums[i], dp[i-1][1])
        return max(dp[len(nums)-1][0], dp[len(nums)-1][1])

213. 打家劫舍2

题目：213. 打家劫舍 II - 力扣（LeetCode）open in new window

难度：中等

其实本题就是在打家劫舍1的基础上添加了一个限制：即头和尾不能同时偷，所以直接分两种情况：不偷第一家、不偷最后一家。那两家都不偷需要额外考虑吗？不需要，包含在内了。

方法1：递归

时间复杂度：O(n)

空间复杂度：O(n)

class Solution:
    def rob(self, nums) -> int:
        if len(nums) == 1: 
            return nums[0]

        # 递归
        @lru_cache(None)
        def backtrack(i):
            if i < 0: return 0
            if i == 0: return self.nums[0]

            no = backtrack(i-1)
            yes = backtrack(i-2) + self.nums[i]
            return max(no, yes)

        self.nums = nums[: -1]
        head = backtrack(len(self.nums)-1)

        backtrack.cache_clear()  # 一定要清空

        self.nums = nums[1: ]
        tail = backtrack(len(self.nums)-1)
        return max(head, tail)

方法2：动归

class Solution:
    def rob(self, nums) -> int:
        if len(nums) == 1:
            return nums[0]
        def rob_func(nums, begin, end):
            dp = [0] * len(nums[begin: end])
            if len(nums[begin: end]) <= 0:
                return 0
            if len(nums[begin: end]) == 1:
                return nums[begin]

            dp[0] = nums[begin: end][0]
            dp[1] = max(dp[0], nums[begin: end][1])
            for i in range(2, len(dp)):
                dp[i] = max(dp[i-1], dp[i-2] + nums[begin: end][i])
            return dp[len(dp)-1]

        res1 = rob_func(nums, 0, len(nums)-1)
        res2 = rob_func(nums, 1, len(nums))
        return max(res1, res2)

class Solution:
    def rob(self, nums) -> int:
        if len(nums) == 0: return 0
        if len(nums) == 1: return nums[0]

        def robFunc(nums, begin, end):
            if len(nums[begin: end]) == 0:
                return 0
            if len(nums[begin: end]) == 1:
                return nums[begin: end][0]

            dp = [[0, 0] for i in range(len(nums[begin: end]))]
            dp[0][1] = nums[begin: end][0]
            dp[1][0] = dp[0][1]
            dp[1][1] = max(nums[begin: end][0], nums[begin: end][1])

            for i in range(2, len(dp)):
                dp[i][0] = max(dp[i-1][0], dp[i-1][1])
                dp[i][1] = max(dp[i-2][0] + nums[begin: end][i],
                               dp[i-2][1] + nums[begin: end][i])

            return max(dp[-1][0], dp[-1][1])

        res1 = robFunc(nums, 0, len(nums) - 1)
        res2 = robFunc(nums, 1, len(nums))
        return max(res1, res2)

377. 打家劫舍3

题目：337. 打家劫舍 III - 力扣（LeetCode）open in new window

难度：中等

方法1：回溯

这里函数backtrack的参数需要好好想想为啥要传入一个choose，如果不传入这个，在分情况讨论是否选node的时候，还要判断node.right和node.left是否为空，显得代码很冗余。其次就是对同一种情况下（choose值一定的情况下），就比如choose=True，计算得到的两个值是应该相加而不是取最大值。

下面的代码会超时，加一个@lru_cache勉强可以通过，但是执行时间还是很长。

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def rob(self, root) -> int:
        def backtrack(node, choose):
            if node is None:
                return 0

            if choose:  # 选根节点的时候，左右子节点一定不能选
                no_choose_l = backtrack(node.left, False)
                no_choose_r = backtrack(node.right, False)
                val = no_choose_l + no_choose_r + node.val
            else:  # 不选根节点的时候，有几种情况
                choose_l = backtrack(node.left, True)
                choose_r = backtrack(node.right, True)
                no_choose_l = backtrack(node.left, False)
                no_choose_r = backtrack(node.right, False)
                val = max(choose_l, no_choose_l) + max(choose_r, no_choose_r)
            return val

        val1 = backtrack(root, False)  # 不选根节点
        val2 = backtrack(root, True)  # 选根节点
        return max(val1, val2)

时间复杂度：O(n)，空间复杂度：O(log n+n)（系统栈+cache）

方法2：动归

参考代码随想录 (programmercarl.com)open in new window

若使用dp来做，那就是树形dp，树形dp的dp列表只需要考虑每一层需要多少即可，因为递归会将每一层的dp列表记录下来。

每一个节点有两种状态，偷或不偷，所以dp数组（dp table）以及下标的含义：下标为0记录不偷该节点所得到的的最大金钱，下标为1记录偷该节点所得到的的最大金钱。

注意dp[0]和dp[1]存的值的含义，它应该是最大金钱，所以它是考虑了所有情况的结果，比如下面的写法就是错的：

        // if rob root
        dp[1] = dpl[0] + dpr[0] + root->val;
        // if not rob root
        dp[0] = dpl[1] + dpr[1];

因为对于rob root的时候，确实只有一种情况，即左右子树都不能rob；而对于not rob root的时候，有两种情况，一种是rob左右子树，一种是不rob左右子树，而上述代码只有rob左右子树这一种情况，所以dp[0]并不是最优结果。应该改为如下：

        // if rob root
        dp[1] = dpl[0] + dpr[0] + root->val;
        // if not rob root
        dp[0] = max(dpl[1], dpl[0]) + max(dpr[1], dpr[0]);

整体代码：

class Solution {
public:
    vector<int> rob_func(TreeNode* root) {
        if (root == nullptr) return vector<int>{0, 0};

        // 后序遍历
        vector<int> dpl(2, 0);
        vector<int> dpr(2, 0);
        dpl = rob_func(root->left);
        dpr = rob_func(root->right);

        vector<int> dp(2, 0);
        // if rob root
        dp[1] = dpl[0] + dpr[0] + root->val;
        // if not rob root
        dp[0] = max(dpl[1], dpl[0]) + max(dpr[1], dpr[0]);
        return dp;
    }
    int rob(TreeNode* root) {
        vector<int> dp = rob_func(root);
        return max(dp[0], dp[1]);
    }
};

时间复杂度和空间复杂度分别为：O(n), O(logn)

121.买股票的最佳时机

题目：121. 买卖股票的最佳时机 - 力扣（LeetCode）open in new window

难度：简单

注意题目的要求，即只能买入一次、卖出一次，不能多次买入多次卖出。

方法1：穷举法

找出所有的差值，返回最大值。超时。

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if(prices.size() <= 1) return 0;
        int res = 0;
        for (int i = 0; i < prices.size() - 1; i++){
            for (int j = i + 1; j < prices.size(); j++){
                res = max(res, prices[j] - prices[i]);
            }
        }
        return res;
    }
};

方法2：贪心

思路：将最大价格从末尾往前扩散，从最后往前遍历，同时更新最大价格并计算差值，保留最大差值，最终结果就是该最大差值.

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if (prices.size() < 2) return 0;
        int p = prices.size() - 2;
        int m = prices[prices.size() - 1];
        int res = 0;
        while (p >= 0){
            if (m > prices[p]) res = max(res, m - prices[p]);
            else m = prices[p];
            p--;
        }
        return res;
    }
};

很多其他的贪心解法和我的遍历方向相反，即从头开始遍历，保留最小价格，实质都是一样的。

时间复杂度：O(n)，空间复杂度：O(1)。

方法3：动归

有一种动归的做法其实和贪心思路很像，贪心的空间复杂度是这种动归的优化版，参见121. 买卖股票的最佳时机 - 力扣（LeetCode）open in new window。

还有一种，在代码随想录 (programmercarl.com)open in new window，这种解法的核心思路是先创建dp，形状为[len(prices), 2]，然后dp[i][0]表示的含义是：第i天持有股票所得最多现金；dp[i][1]表示：第i天不持有股票所得最多现金。这里弄清持有和买入的区别：持有表示手头已经有股票了，可能是今天买的，也可能是昨天买的；而买入表示今天买。

所以最终的解是最后一天持有和不持有股票两种情况下，收益最高的情况的收益值。

如果第i天持有股票即dp[i][0]， 那么可以由两个状态推出来

  • 第i-1天就持有股票，那么就保持现状，所得现金就是昨天持有股票的所得现金 即：dp[i - 1][0]
  • 第i天买入股票，所得现金就是买入今天的股票后所得现金即：-prices[i]

那么dp[i][0]应该选所得现金最大的，所以dp[i][0] = max(dp[i - 1][0], -prices[i]);

如果第i天不持有股票即dp[i][1]， 也可以由两个状态推出来

  • 第i-1天就不持有股票，那么就保持现状，所得现金就是昨天不持有股票的所得现金 即：dp[i - 1][1]
  • 第i天卖出股票，所得现金就是按照今天股票价格卖出后所得现金即：prices[i] + dp[i - 1][0]

同样dp[i][1]取最大的，dp[i][1] = max(dp[i - 1][1], prices[i] + dp[i - 1][0]);

从上面的状态转移分析来看，有一个核心的思想：我一开始手头金额=0，若买入prices[i]，则手头金额为-prices[i]，若卖出prices[i]，则手头金额+prices[i]。

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int len = prices.size();
        if (len == 0) return 0;
        vector<vector<int>> dp(len, vector<int>(2));
        dp[0][0] -= prices[0];
        dp[0][1] = 0;
        for (int i = 1; i < len; i++) {
            dp[i][0] = max(dp[i - 1][0], -prices[i]);
            dp[i][1] = max(dp[i - 1][1], prices[i] + dp[i - 1][0]);
        }
        return dp[len - 1][1];
    }
};

看状态转移方程可以发现，当前步只和前一步相关，空间复杂度可以进一步优化。

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if (prices.size() == 0) return 0;
        vector<int> dp(2, 0);
        // init
        dp[0] = 0;  // 第0天不买入
        dp[1] = -prices[0];  // 第0天买入
        // update
        for (int i = 1; i < prices.size(); i++) {
            // not hand
            dp[0] = max(dp[0], dp[1] + prices[i]);
            // hand
            dp[1] = max(dp[1], -prices[i]);
        }
        return dp[0];
    }
};

122. 买卖股票的最佳时机2

题目：122. 买卖股票的最佳时机 II - 力扣（LeetCode）open in new window

难度：中等

这个题的要求是：可以多次买入和卖出，注意和1的区别。

方法1：贪心

贪心的核心思路是，每一次取前一天的价格和后一天的价格，若后一天的价格<前一天，则不买；若后一天的价格>前一天，则买入。

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if (prices.size() < 2) return 0;
        int pre = 0, ans = 0;
        for (int nex = 1; nex < prices.size(); nex ++) {
            if (prices[nex] > prices[pre]) ans = ans + prices[nex] - prices[pre];
            pre = nex;
        }
        return ans;
    }
};

方法2：动归

思路其实和买卖股票1的思路一样，但是要注意两个题的区别，1是只能买卖一次，2是可以多次买卖，如果按照1的动归思路来看很难看出来1的状态转移方程为何不能用在2上。其实买卖一次和多次的区别在于，每次要买之前，手头的钱是不同的。只能买卖一次，买之前手头的钱一定=0；可以买卖多次，买之前手头的钱不一定为0。

根据这个思路，将状态转移方程改为：

若第 i 天不持有股票，最大收益为max(昨天也不持有，昨天持有今天卖出)：

dp[i][0]=max(dp[i−1][0],dp[i−1][1]+prices[i])

若第 i 天持有股票，最大收益为max(昨天持有，昨天不持有今天买入)：

dp[i][1]=max(dp[i−1][1],dp[i−1][0]−prices[i])

则代码：

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if (prices.size() < 2) return 0;
        vector<vector<int>> dp(prices.size(), vector<int>(2, 0));
        // init
        dp[0][0] = 0;
        dp[0][1] = -prices[0];
        // update
        for (int i = 1; i < prices.size(); i ++) {
            // not get
            dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i]);
            // get
            dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i]);
        }
        return dp[prices.size() - 1][0];
    }
};

123. 买卖股票的最佳时机3

题目：123. 买卖股票的最佳时机 III - 力扣（LeetCode）open in new window

难度：困难

注意题干要求和之前版本的买卖股票的区别，这次限制最多买卖两次，而且不能同时买卖，要卖出之后才可以开始下一次买卖。

方法1：动归

本动归思路是将每一天分为四个状态：第一次持有股票、第一次不持有、第二次持有股票、第二次不持有。注意持有和买入的区别。所以dp数组维度为：[len(prices), 4]。

当天第一次持有股票有两种可能：前一天第一次持有；前一天第一次不持有，今天第一次买入(第一次买入手头的钱一定=0)：

dp[i][0]=max(dp[i−1][0],−p)

当天第一次不持有股票有两种可能：前一天第一次不持有；前一天持第一次持有，今天第一次卖出：

dp[i][1]=max(dp[i−1][1],dp[i−1][0]+p)

当天第二次持有股票有两种可能：昨天第二次持有；昨天第一次不持有，今天第二次买入：

dp[i][2]=max(dp[i−1][2],dp[i−1][1]−p)

当天第二次不持有股票有两种可能：昨天就第二次不持有；昨天第二次持有，今天第二次卖出：

dp[i][3]=max(dp[i−1][3],dp[i−1][2]+p)
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if (prices.size() < 2) return 0;
        int k = 2;
        vector<vector<int>> dp(prices.size(), vector<int>(2 * k, 0));
        // init
        dp[0][0] = -prices[0]; // 第一天第一次持有
        dp[0][1] = 0;  // 第一天第一次不持有
        dp[0][2] = -prices[0]; // 第一天第二次持有
        dp[0][3] = 0; // 第一天第二次不持有
        // update 
        int p = 0;
        for (int i = 1; i < prices.size(); i ++) {
            p = prices[i];
            dp[i][0] = max(dp[i-1][0], -p);  // 第一次持有可能是前一天就持有，还可能是前一天没动作，第一次没动作，手头初始值=0
            dp[i][1] = max(dp[i-1][1], dp[i-1][0] + p);
            dp[i][2] = max(dp[i-1][2], dp[i-1][1] - p);
            dp[i][3] = max(dp[i-1][3], dp[i-1][2] + p);
        }
        return dp[prices.size() - 1][3];
    }
};

同样，看状态转移方程可以发现当前状态只和前一个状态相关，所以可以将空间复杂度降为O(1)。

188. 买卖股票的最佳时机4

题目：188. 买卖股票的最佳时机 IV - 力扣（LeetCode）open in new window

难度：困难

最多可以完成K次买卖。

方法1：动归

从上一题的状态转移方程中可以发现一些规律，每一天有2k种状态，这些状态中间隔性的表示第k次持有和不持有股票，而持有的时候，状态转移方程为：

dp[i][j]=max(dp[i−1][j],dp[i−1][j−1]−p)

不持有的时候，状态转移方程为：

dp[i][j]=max(dp[i−1][j],dp[i−1][j−1]+p)

但是注意的是，第一次持有的时候不能带入上述公式中，第一次持有的时候应该为：

dp[i][j]=max(dp[i−1][j],−p)

但是这样写代码的时候得多一个分类讨论，为了解决这个问题就多加一个状态，即每天有2k+1个状态，这多出来的状态表示的含义是：今天不做任何动作。这样其实值为0，刚好符合结果的正确性，而且也不违背通式结构的一致性：

class Solution {
public:
    int maxProfit(int k, vector<int>& prices) {
        vector<vector<int>> dp(prices.size(), vector<int>(2 * k + 1, 0));
        // init  第一天不论第几次持有，最大收益都是初始为-prices[0]
        for (int j = 1; j < 2 * k + 1; j+=2) {
            dp[0][j] = -prices[0];
        }
        // update
        for (int i = 1; i < prices.size(); i++) {
            int p = prices[i];
            for (int j = 1; j < 2 * k + 1; j++) {
                if (j % 2 != 0) {  // j 为奇数，表示持有
                    dp[i][j] = max(dp[i-1][j], dp[i-1][j-1] - p);
                }
                else {  // j 为偶数，表示不持有
                    dp[i][j] = max(dp[i-1][j], dp[i-1][j-1] + p);
                }
            }
        }
        return dp[prices.size()-1][2 * k];
    }
};

同样可以将空间复杂度降为O(1)。

本题我一开始是将每天分为三种状态：持有股票、不持有、冷冻期。但是发现不对，主要是因为若今天是冷冻期，那么金额应该=昨天是卖出状态的金额，但是若只有上面三种状态无法区分不持有和卖出状态，不持有包含了卖出：

class Solution {

        // init
        dp[0][0] = -prices[0];  // 持有

714. 买卖股票的最佳时机含手续费

题目：714. 买卖股票的最佳时机含手续费 - 力扣（LeetCode）open in new window

难度：中等

有手续费之后，啥时候买入股票的就不能统一用持有状态表示了。需要分为之前买入的和今天买入的。

每天分为三种状态：今天买入，之前买入的，不持有股票。

若今天买入，昨天肯定不持有：

dp[i][0]=dp[i−1][2]−prices[i]−fee

若今天之前买入的，可能昨天买入的，可能更早买入的：

dp[i][1]=max(dp[i−1][0],dp[i−1][1])

若不持有股票，昨天可能买入然后今天卖出，昨天之前买入今天卖出，昨天不持有股票：

dp[i][2]=max(dp[i−1][0]+prices[i],dp[i−1][1]+prices[i],dp[i−1][2])
class Solution {
public:
    int maxProfit(vector<int>& prices, int fee) {
        vector<vector<int>>dp(prices.size(), vector<int>(3, 0));
        // init
        dp[0][0] = -(fee + prices[0]);  // 持有，今天买的
        dp[0][1] = -(fee + prices[0]);  // 持有，今天之前买的
        dp[0][2] = 0;  // 不持有

        // update
        for (int i = 1; i < prices.size(); i++) {
            dp[i][0] = dp[i-1][2] - prices[i] - fee;
            dp[i][1] = max(dp[i-1][0], dp[i-1][1]);
            dp[i][2] = max(max(dp[i-1][0], dp[i-1][1]) + prices[i], dp[i-1][2]);
        }
        return dp[prices.size()-1][2];
    }
};

也可以每天分为三种状态：今天结束交易之后手中无股票，今天结束交易之后手中有股票。

若今天结束交易之后手中无股票，昨天可能有今天卖出，昨天可能也无：

dp[i][0]=max(dp[i−1][0],dp[i−1][1]+prices[i])

若今天结束交易之后手中有股票，昨天可能无今天买入，昨天可能就有股票：

dp[i][1]=max(dp[i−1][0]−fee−prices[i],dp[i−1][1])
class Solution {
public:
    int maxProfit(vector<int>& prices, int fee) {
        vector<vector<int>>dp(prices.size(), vector<int>(2, 0));
        // init
        dp[0][0] = 0;
        dp[0][1] = -(fee+prices[0]);
        // update
        for (int i = 1; i < prices.size(); i++) {
            dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i]);
            dp[i][1] = max(dp[i-1][0] - fee - prices[i], dp[i-1][1]);
        }
        return dp[prices.size()-1][0];
    }
};
