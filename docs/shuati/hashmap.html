哈希表

Makeittrue2024/2/13刷题刷题

INFO

通常涉及到字符串的题目，如果题目说明了都是小写字母或者其他特殊说明，其实可以用数组来代替哈希表。当然用map确实可以，但使用map的空间消耗要比数组大一些，因为map要维护红黑树或者符号表，而且还要做哈希函数的运算。

使用数组作为哈希表有这样的特点：

  • 数组的大小是有限的，受到系统栈空间（不是数据结构的栈）的限制。
  • 如果数组空间够大，但哈希值比较少、特别分散、跨度非常大，使用数组就造成空间的极大浪费。

242. 有效的字母异位词

题目：242. 有效的字母异位词open in new window

难度：简单

方法1：先排序，然后逐个比较

时间复杂度：O(nlogn+n)

空间复杂度：O(m+n)。排序之后是新的字符串

方法2：哈希表

思路是先用hashmap统计s里每一个字符的数量，然后遍历t中的字符并减少hashmap相应字符的数量，若出现<0，则返回False。

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t): return False
        def convert(char):
            return ord(char) - ord('a')
        hashmap = [0] * 26
        for char in s:
            hashmap[convert(char)] += 1

        for char in t:
            hashmap[convert(char)] -= 1
            if hashmap[convert(char)] < 0:
                return False

        return True

进阶: 如果输入字符串包含 unicode 字符怎么办？你能否调整你的解法来应对这种情况？

Unicode是为了解决传统字符编码的局限性而产生的方案，它为每个语言中的字符规定了一个唯一的二进制编码。而 Unicode中可能存在一个字符对应多个字节的问题.

49. 字母异位词分组

题目：49. 字母异位词分组open in new window

难度：中等

方法1：朴素法

最朴素的想法，每一次将strs[i]加入一个新列表，然后从其后续的单词开始继续遍历，若两个单词是异位词，则将其加入，并标记为已经使用过。遍历结束后，将该列表加入ans：

时间复杂度：O(n2×k)。n是单词表长度，k是单词长度

空间复杂度：O(n+26)

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        def convert(char):
            return ord(char) - ord('a')

        def same(str1, str2):
            if len(str1) != len(str2): return False
            hashmap = [0] * 26
            for char in str1:
                hashmap[convert(char)] += 1
            for char in str2:
                hashmap[convert(char)] -= 1
                if hashmap[convert(char)] < 0: return False
            return True

        ans = []
        used = [False] * len(strs)
        for i in range(len(strs)):
            if used[i]: continue
            lyst = [strs[i]]
            used[i] = True
            for j in range(i+1, len(strs)):
                if used[j]: continue
                if same(lyst[0], strs[j]):
                    lyst.append(strs[j])
                    used[j] = True
            ans.append(lyst)

        return ans

方法2：排序

这个方法的思路遍历每一个字符串，将其排序，看是否存在哈希表中，若存在，则加入；若不存在，将其作为哈希表的键。

时间复杂度：O(klogk×n)，n是单词表长度，k是单词长度。

空间复杂度：O(nk)。多了一个哈希表

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        hashmap = {}
        ans = []
        for s in strs:
            new_s = ''.join(sorted(s))
            hashmap[new_s] = hashmap.get(new_s, [])
            hashmap[new_s].append(s)

        for val in hashmap.values():
            ans.append(val)
        return ans

方法3：计数

思路：将每一个字符串的字母都统计一下，将这个数量值列表作为哈希表的键。但是两个异位词的单词位置不同，可能统计的数量是错位的怎么办？这里直接为每一个字符串定义一个长度为26的数组，将这个数组作为哈希表的key：

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        hashmap = defaultdict(list)
        for s in strs:
            count = [0] * 26
            for ch in s:
                count[ord(ch) - ord('a')] += 1
            hashmap[tuple(count)].append(s)
        return list(hashmap.values())

时间复杂度：O(n(k+26))，这里的26不是遍历时间，而是生成哈希表的键的耗时。更新哈希表的时间复杂度为O(1)。

空间复杂度：O(n(k+26))。主要是哈希表的空间，count数组可以忽略不计。

349. 两个数组的交集

题目：349. 两个数组的交集open in new window

难度：简单

方法1：两个集合

class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        set1 = set(nums1)
        set2 = set(nums2)
        ans = []
        for n in set1:
            if n in set2:
                ans.append(n)
        return ans

时间复杂度：O(m+n)，其中 m 和 n 分别是两个数组的长度。使用两个集合分别存储两个数组中的元素需要 O(m+n) 的时间，遍历较小的集合并判断元素是否在另一个集合中需要 O(min⁡(m,n))的时间，因此总时间复杂度是 O(m+n)。

空间复杂度：O(m+n），其中 m 和 n 分别是两个数组的长度。空间复杂度主要取决于两个集合。

方法2：排序+双指针

思路是：先对两个列表排序，然后两个指针来控制移动，若nums1[i] < nums[j]，则移动i，若相等则一起移动，并将nums1[i]加入ans。但是答案要求不重复，考虑到ans内一定是有序的，所以可以使用一种简单的方式去重：用一个变量pre表示存入ans的最新元素的值，若新加入的和pre相等，则不加入。

时间复杂度：主要在排序上。O(mlogm+nlogn)

空间复杂度：如果不去额外使用新的数组来存放排序后的内容，那么空间复杂度主要取决于排序算法中用到的额外空间(这个一般不需要这样考虑，因为很多排序算法的空间复杂度为O(1)。O(1)

class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        lyst1 = sorted(nums1)
        lyst2 = sorted(nums2)
        p1 = 0
        p2 = 0
        ans = []
        while p1 < len(lyst1) and p2 < len(lyst2):
            if lyst1[p1] < lyst2[p2]:
                p1 += 1
            elif lyst1[p1] > lyst2[p2]:
                p2 += 1
            else:
                pre = ans[-1] if len(ans) > 0 else -1
                if pre != lyst1[p1]:
                    ans.append(lyst1[p1])
                p1 += 1
                p2 += 1
        return ans

350. 两个数组的交集2

题目：350. 两个数组的交集 IIopen in new window

难度：简单

方法1：哈希表

时间复杂度：O(m+n)

空间复杂度：O(min(m,n))

class Solution:
    def intersect(self, nums1: List[int], nums2: List[int]) -> List[int]:
        ans = []
        hashmap = {}
        if len(nums1) > len(nums2):
            return self.intersect(nums2, nums1)
        for n in nums1:
            hashmap[n] = hashmap.get(n, 0) + 1

        for n in nums2:
            if n in hashmap and hashmap[n] > 0:
                hashmap[n] -= 1
                ans.append(n)
        return ans

方法2：排序+双指针

和上一题的思路一样，只是不要求结果是不重复的。

时间复杂度：O(mlogm+nlogn)

空间复杂度：O(1)

class Solution:
    def intersect(self, nums1: List[int], nums2: List[int]) -> List[int]:
        ans = []
        nums1 = sorted(nums1)
        nums2 = sorted(nums2)

        p1 = 0
        p2 = 0
        while p1 < len(nums1) and p2 < len(nums2):
            if nums1[p1] < nums2[p2]:
                p1 += 1
            elif nums1[p1] > nums2[p2]:
                p2 += 1
            else:
                ans.append(nums1[p1])
                p1 += 1
                p2 += 1
        return ans

进阶问题：

  • 如果给定的数组已经排好序呢？你将如何优化你的算法？

    如果是已经排序的，方法2的时间复杂度就降为O(min(m,n)).

  • 如果 nums1 的大小比 nums2 小，哪种方法更优？

    哈希表方法更优

  • 如果 nums2 的元素存储在磁盘上，内存是有限的，并且你不能一次加载所有的元素到内存中，你该怎么办？

    如果nums1很小：无法高效地对 nums2进行排序，因此推荐使用方法一而不是方法二。在方法一中，nums2只关系到查询操作，因此每次读取 nums2中的一部分数据，并进行处理即可。

    如果nums1也很大：通过归并外部排序将两个数组排序后再使用排序双指针查找

202. 快乐数

题目：202. 快乐数open in new window

难度：简单

方法1：哈希表

看到题目有点不敢动手，因为担心会不会即便不等于1，还是会一直死循环（一直无穷增大），这样无法找到跳出循环的出口。实际这是不会的，即这样计算快乐数的过程最终只有两个结果：或者回到之前已经计算过的数，或者最终=1。

为什么不会值越来越大最后接近无穷大呢？

DigitsLargestNext
1981
299162
3999243
49999324
1399999999999991053

列举几种长度的最大值的情况，计算得到下一个数都会有所下降。所以值越来越大的情况永远不会发生。

时间复杂度：O(logn)。查找给定数字的下一个值的成本为 O(log⁡n)，因为我们正在处理数字中的每位数字，而数字中的位数由 log⁡n 给定。如果将每一个计算出来的结果作为图的节点，那么图的总节点数主要和logn有关，所以绘制完整个图的时间复杂度为O(logn)。所以整体时间复杂度还是O(logn)

时间复杂度：O(logn). 主要和图的节点数有关，存在哈希表内。

class Solution:
    def split_and_sum(self, n):
        res = 0
        while n > 0:
            sub = n % 10
            n -= sub
            n /= 10
            res += sub ** 2
        return res

    def isHappy(self, n: int) -> bool:
        set_ = set()
        while True:
            n = self.split_and_sum(n)
            if n == 1: 
                return True
            elif n in set_:   # 重复出现，说明出现了死循环
                return False
            else:
                set_.add(n)

方法2：快慢指针

将问题转化为：检测是否会出现环。若快指针和慢指针相遇，则一定存在环。

class Solution:
    def split_and_sum(self, n):
        res = 0
        while n > 0:
            sub = n % 10
            n -= sub
            n /= 10
            res += sub ** 2
        return res

    def isHappy(self, n: int) -> bool: 
        slow = n
        fast = self.split_and_sum(self.split_and_sum(n))
        while fast != slow and fast != 1:
            fast = self.split_and_sum(self.split_and_sum(fast))
            slow = self.split_and_sum(slow)
        return fast == 1

1. 两数之和

题目：1. 两数之和open in new window

难度：简单

方法1：暴力

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        for i in range(len(nums)):
            for j in range(i+1, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i, j]
        return []

方法2：哈希表

思路：如果相加=target的两个数都在nums内，那么经过第一个数时将其记录下去，待经过第二个数时需要能快速找到这个数。这个时候就可以用哈希表来记录。

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        hashmap = {}
        for i in range(len(nums)):
            if target - nums[i] in hashmap:
                return [i, hashmap[target - nums[i]]]
            else:
                hashmap[nums[i]] = i
        return []

454. 四数相加2

题目：454. 四数相加 IIopen in new window

难度：中等

方法1：哈希表

时间复杂度：O(m×n+k×l)，这分别是四个数组的长度

空间复杂度：O(mn)

思路和上一题的方法2一样，换到这个题就是先拿两个数组，将其和都存起来，后面再遍历后两个数组的组合。

class Solution:
    def fourSumCount(self, nums1: List[int], nums2: List[int], nums3: List[int], nums4: List[int]) -> int:
        hashmap = {}
        for i in range(len(nums1)):
            for j in range(len(nums2)):
                key = nums1[i] + nums2[j]
                hashmap[key] = hashmap.get(key, 0) + 1

        ans = 0
        for i in range(len(nums3)):
            for j in range(len(nums4)):
                key = -(nums3[i] + nums4[j])
                if key in hashmap:
                    ans += hashmap[key]
        return ans

383. 赎金信

题目：383. 赎金信open in new window

难度：简单

方法1：哈希表+计数

先统计ransomNote里的所有字符，存入哈希表，然后用变量cnt统计需要考虑的字符数，再遍历magazine，每一次遇到一个能抵消ransomNote里的字符，cnt - 1。若cnt=0，则返回true。

class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        hashmap = {}
        cnt = 0
        for char in ransomNote:
            hashmap[char] = hashmap.get(char, 0) + 1
            cnt += 1

        for char in magazine:
            if char in hashmap and hashmap[char] > 0:
                hashmap[char] -= 1
                cnt -= 1
            if cnt == 0: return True
        return False
