232. 用栈实现队列

题目：232. 用栈实现队列open in new window

难度：简单

如何使用两个栈来模拟队列的基本操作？

一种实现（这种实现的特点是，每次要pop的时候，将q1的值加到q2去，然后q2弹出，随后又将q2的值加入q1中）：

class MyQueue:

    def __init__(self):
        self.q1 = deque()
        self.q2 = deque()

    def push(self, x: int) -> None:
        self.q1.append(x)

    def pop(self) -> int:
        while self.q1:
            self.q2.append(self.q1.pop())
        val = self.q2.pop()
        while self.q2:
            self.q1.append(self.q2.pop())
        return val

    def peek(self) -> int:
        while self.q1:
            self.q2.append(self.q1.pop())
        val = self.q2.pop()
        self.q2.append(val)
        while self.q2:
            self.q1.append(self.q2.pop())
        return val

    def empty(self) -> bool:
        if self.q1: return False
        return True

上一种实现太耗时，很多操作多余，下面这种操作每次pop的时候判断q2是否为空，若不为空，则直接pop，为空，则将q1的值转移到q2中(即q1和q2明确分工，前者用于接收加入的数据，后者用于弹出数据)：

class MyQueue:

    def __init__(self):
        self.q1 = deque()
        self.q2 = deque()

    def push(self, x: int) -> None:
        self.q1.append(x)

    def pop(self) -> int:
        if not self.q2:
            while self.q1:
                self.q2.append(self.q1.pop())
        return self.q2.pop()

    def peek(self) -> int:
        val = self.pop()
        self.q2.append(val)
        return val

    def empty(self) -> bool:
        if self.q1 or self.q2: return False
        return True

时间复杂度：peek() , pop() 函数在 N 次队首元素删除操作中总共需完成 N 个元素的倒序，均摊时间复杂度为 O(1)。

空间复杂度：空间复杂度 O(N) ： 最差情况下，栈 A 和 B 共保存 N 个元素

225. 用队列实现栈

题目：225. 用队列实现栈open in new window

难度：简单

我的思路是：先规定q1用于接收加入的数据，假设数据量为size，弹出数据时，将q1弹出size-1个数，然后将这些数同时加入q2（备份数据），最后将q1的数弹出并返回。注意q1和q2的角色不同，所以弹出之后还要将q1和q2变量交换一下。

class MyStack:

    def __init__(self):
        self.q1 = deque()
        self.q2 = deque()
        self.size = 0

    def push(self, x: int) -> None:
        self.q1.append(x)
        self.size += 1

    def pop(self) -> int:
        for i in range(self.size-1):
            val = self.q1.popleft()
            self.q2.append(val)
        val = self.q1.popleft()
        self.size -= 1
        self.q1, self.q2 = self.q2, self.q1
        return val

    def top(self) -> int:
        val = self.pop()
        self.push(val)
        return val

    def empty(self) -> bool:
        return self.size == 0

时间复杂度：pop操作为O(n)，其他为O(1)

空间复杂度：O(n)

上面代码是用两个队列实现栈，如何使用一个队列？

思路：将队列弹出size-1个数并加入队列，再将队列的队头数据弹出，这就实现了pop功能。

class MyStack:

    def __init__(self):
        self.q1 = deque()
        self.size = 0

    def push(self, x: int) -> None:
        self.q1.append(x)
        self.size += 1

    def pop(self) -> int:
        for i in range(self.size-1):
            val = self.q1.popleft()
            self.q1.append(val)
        val = self.q1.popleft()
        self.size -= 1
        return val

    def top(self) -> int:
        val = self.pop()
        self.push(val)
        return val

    def empty(self) -> bool:
        return self.size == 0

20. 有效的括号

题目：20. 有效的括号open in new window

难度：简单

方法1：栈

class Solution:
    def isValid(self, s: str) -> bool:
        hashmap = {'{': '}', '[': ']', '(': ')'}
        stack = deque()

        for ch in s:
            if ch in hashmap:
                stack.append(ch)  # 左括号入栈
            else:  # 若为右括号
                if stack: 
                    left = stack.pop()
                    if hashmap[left] != ch:  # 左右括号不配对
                        return False
                else:  # 若栈空则有剩余右括号未匹配
                    return False
        return len(stack) == 0  # 若还有左括号未配对，则False

150. 逆波兰表达式求值

题目：150. 逆波兰表达式求值open in new window

难度：中等

逆波兰表达式是一种后缀表达式，所谓后缀就是指算符写在后面。

  • 平常使用的算式则是一种中缀表达式，如 ( 1 + 2 ) * ( 3 + 4 ) 。
  • 该算式的逆波兰表达式写法为 ( ( 1 2 + ) ( 3 4 + ) * ) 。

逆波兰表达式主要有以下两个优点：

  • 去掉括号后表达式无歧义，上式即便写成 1 2 + 3 4 + * 也可以依据次序计算出正确结果。
  • 适合用栈操作运算：遇到数字则入栈；遇到算符则取出栈顶两个数字进行计算，并将结果压入栈中

方法1：栈

class Solution:
    def compute(self, n1, n2, op):
        if op == '+': return n1 + n2
        if op == '-': return n1 - n2
        if op == '*': return n1 * n2
        if op == '/': return int(n1 / n2)

    def evalRPN(self, tokens: List[str]) -> int:
        stack = deque()
        op = {'+', '-', '*', '/'}
        for ch in tokens:
            if ch not in op:  # 数字
                stack.append(ch)
            else:
                n2 = stack.pop()
                n1 = stack.pop()
                val = self.compute(int(n1), int(n2), ch)
                stack.append(val)
        return int(stack.pop())

239. 滑动窗口最大值

题目：239. 滑动窗口最大值open in new window

难度：困难

方法1：优先队列

用python自带的优先队列来实现：

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        # 注意 Python 默认的优先队列是小根堆
        q = [(-nums[i], i) for i in range(k)]
        heapq.heapify(q)

        ans = [-q[0][0]]
        for i in range(k, n):
            heapq.heappush(q, (-nums[i], i))
            while q[0][1] <= i - k: # 不断地移除堆顶的元素，直到其出现在滑动窗口中
                heapq.heappop(q)
            ans.append(-q[0][0])

        return ans

时间复杂度：将一个元素放入优先队列的时间复杂度为 O(log⁡n)，因此总时间复杂度为 O(nlog⁡n)。

空间复杂度：O(n)，即为优先队列需要使用的空间。

方法2：单调队列

满足单调性的双端队列一般称作「单调队列」。

思路是维护一个单调队列其中存的是单调递减的数。预备阶段先对初始窗口内的数入队，大的数压入队头，小数被弹出，从而保证是单调的。然后继续遍历后续的数，模拟窗口的滑动，窗口滑动时，会弹出左边的数，加入右边的数，加入新的数好说，和前面压入队的思路一样；但是弹出左边的数，若该数是窗口内最大的数（等于queue[0]）,则queue.pop(0)，否则不用管。

时间复杂度：O(n)，其中 n 是数组 nums 的长度。每一个下标恰好被放入队列一次，并且最多被弹出队列一次，因此时间复杂度为 O(n)

空间复杂度：下面使用deque的方法的复杂度为O(k)，但我自己实现的这种应该大于O(k)。

class Solution:
    def append(self, queue, n):
        while queue and n > queue[-1]:
            queue.pop()
        queue.append(n)

    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        queue = []
        window = nums[: k]
        for n in window:
            self.append(queue, n)

        ans = [queue[0]]
        for i in range(k, len(nums)):
            pop_num = nums[i-k]
            if pop_num == queue[0]:
                queue.pop(0)
            self.append(queue, nums[i])
            ans.append(queue[0])
        return ans

使用deque，换一种思路来管理队头元素，队头永远是最大值，但若不属于窗口内，则弹出：

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        q = collections.deque()
        for i in range(k):
            while q and nums[i] >= nums[q[-1]]:  # 使得队列保持单调递减
                q.pop()
            q.append(i)

        ans = [nums[q[0]]]
        for i in range(k, n):
            while q and nums[i] >= nums[q[-1]]:  # 使得队列保持单调递减
                q.pop()
            q.append(i)
            while q[0] <= i - k:  # 若队列头元素超出窗口范围，弹出
                q.popleft()
            ans.append(nums[q[0]])

        return ans

方法3：分块处理

将nums按照大小为k分块，若窗口某个时刻刚好等于一个分块的区域，那么窗口的最大值=该分块的最大值；若窗口某个时刻跨越了两个分块，则窗口内最大值=max(前一个分块的后缀中最大值，后一个分块的前缀最大值)，下图不同颜色表示不同分块，此时窗口刚好跨越前两个分块：

为了让找到最大值更高效，为nums构建前缀表和后缀表，用于统计每一个分块的前后缀中的最大值，然后再根据上述的求窗口内最大值公式来求解ans：

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        prefix_max = [0] * n
        suffix_max = [0] * n

        # 填写分块前缀最大值
        for i in range(n):
            if i % k == 0:  # 分块的第一个值
                prefix_max[i] = nums[i]
            else:
                prefix_max[i] = max(prefix_max[i-1], nums[i])

        # 填写分块后缀最大值
        for i in range(n-1, -1, -1):
            # 最后一个分块可能不足k个数，所以n-1是特殊情况
            # 注意何时为分块末，i%k=0不是，而是分块开头
            if i == n-1 or (i+1) % k == 0:
                suffix_max[i] = nums[i]
            else:
                suffix_max[i] = max(suffix_max[i+1], nums[i])

        # 计算滑动窗口的最大值
        ans = [max(suffix_max[i], prefix_max[i + k - 1]) for i in range(n - k + 1)]
        return ans

时间复杂度：O(3n)

空间复杂度：O(2n)

374. 前k个高频元素

题目：347. 前 K 个高频元素open in new window

难度：中等

方法1：优先队列

为了让堆本身的内容就是我们需要的结果，那么每次要将小的元素弹出去，所以要维护一个小根堆。python的heapq默认用的是小根堆。

最后得到ans可以直接从后往前遍历q，时间复杂度为O(k)，还可以使用堆弹出元素，ans大小预设置为k，将弹出的元素赋给q的末位。但是每次弹出元素之后，堆会调整一下，所以这样的时间复杂度变成了O(klogk)。所以还是直接遍历q快一些。

整体时间复杂度为：首先遍历nums构建hashmap，O(N)；然后遍历hashmap，前k个元素是构建堆，O(klogk)；后面N-k个元素插入都要调整堆，O((N-k)logk)；最后遍历q，填充ans，O(k)。所以整体时间复杂度为O(Nlogk)

空间复杂度：O(N+k)，一个是哈希表，一个是堆的大小.

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        hashmap = {}
        for n in nums:
            hashmap[n] = hashmap.get(n, 0) + 1

        q = []
        for key, val in hashmap.items():
            heapq.heappush(q, [val, key])
            if len(q) > k:
                heapq.heappop(q)

        ans = []
        for i in range(k-1, -1, -1):
            ans.append(q[i][1])
        return ans

方法2：基于快排

快速排序每次可以固定一个数的位置，假设该数的位置为p，下面分两种情况：

若 p - low > k: 则可以将范围缩小为[low, k-1]，继续搜索

若 p - low <= k: 则可以将这p - low个数先加入ans, 然后继续搜索[p, high]

🤧 但是我下面写的代码有bug未解决(bug已经确定是qsort函数中的if i - low > k那一块判断语句的边界处理地方没有处理好)：

class Solution:
    def qsort(self, pairs, low, high, k):
        if low >= high: # 要特别注意len(pairs)==1的情况
            return
        pivot = pairs[high]
        i = low - 1  # 经验：i = low - 1
        for j in range(low, high):
            # 因为是要选出前 k 个最大的，所以遇到大于 pivot 的需要交换
            if pairs[j][1] > pivot[1]:
                i += 1  # 记得先 + 1
                pairs[i], pairs[j] = pairs[j], pairs[i]

        # 最后将pivot归位
        i += 1
        pairs[i], pairs[high] = pairs[high], pairs[i]

        # 大于pivot的有 i - low 个，那么这些一定是最大的前 i-low 个数
        if i - low > k:  
            # 如果大于要求的数量，可以进一步缩小范围：[low, i-1]，
            # 注意索引为 i 的位置是 pivot
            self.qsort(pairs, low, i-1, k)
        else: 
            # 如果大于要求的数量，那么先将i-low个加入结果列表
            for ind in range(low, i):
                self.ans.append(pairs[ind][0])
            # 还剩余 k - i + low 个
            self.qsort(pairs, i+1, high, k - i + low)


    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        hashmap = {}
        for n in nums:
            hashmap[n] = hashmap.get(n, 0) + 1
        pairs = [[k, hashmap[k]] for k in hashmap.keys()]

        if len(pairs) == 1:  # len(pairs)==1的情况
            return [pairs[0][0]]

        self.ans = []
        self.qsort(pairs, 0, len(pairs)-1, k)
        return self.ans
