多模态跟踪

Makeittrue论文笔记论文笔记

INFO

基于RGB图像的跟踪器已经非常强大，同样也有大量的相关数据集。然而基于纯RGB序列的目标跟踪在极端光照、背景杂波和运动模糊等复杂场景中仍然容易失败。因此，多模态跟踪越来越受到人们的关注，因为它能够利用多模态互补来实现更鲁棒的跟踪，如RGB+Depth (RGB- d)，RGB+Thermal (RGB-T), 和RGB+Event (RGBE)。之前的一些工作通常先在大型RGB数据中训练跟踪器，然后再在多模态数据集中微调模型。但是由于多模态数据集相对较小，模型往往容易忘记在RGB数据中所学习到的知识，而且容易过拟合，随着NLP中的prompt技术的提出，越来越多的方法使用基于视觉信息的prompt来微调视觉模型。在多模态跟踪中也慢慢出现一些相关基于prompt的方法。这类方法甚至可以灵活切换到不同的模态组合，达到更优的结果的同时，需要训练的参数量也更少。

ProTrack

论文：[2207.14571] Prompting for Multi-Modal Trackingopen in new window

代码：未开源

简要介绍：通过将输入的多个模态（两个模态）融合为单个模态，冻结在RGB数据集中预训练的模型，利用该模型来处理融合后的输入，得到预测结果。文章没有训练过程。本文也是第一篇将prompt learning基于用在多模态跟踪上的论文。

文章核心是下面的公式：

f(Vt,At)=λ∗Color(At)+(1−λ)∗Color(Vt)

Vt表示RGB图像，At是额外的模态输入，如深度信息。使用一个染色函数 Color来处理输入的图像，若是RGB图像，不做处理；若只有单通道，则该函数将单通道转为多通道。具体而言，对于深度图像和热图像，使用Color函数求其JET Colormaps，对于event图像，我使用从事件流转换过来的事件图像。λ=0.05。

ViPT

论文：[2303.10826] Visual Prompt Multi-Modal Trackingopen in new window

代码：jiawen-zhu/ViPT: [CVPR23] Visual Prompt Multi-Modal Tracking (github.com)open in new window

简要介绍：冻结在RGB图像中预训练的ViT部分，引入少量的prompter用于模态的互相融合，在下游的多模态数据集上微调。将额外模态数据作为prompts，RGB图像作为主模态。
