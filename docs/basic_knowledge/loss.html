Triplet

深度学习从入门到放飞自我：完全解析triplet loss - 知乎 (zhihu.com)open in new window

思路：让相似的样本之间距离更近，差别大的样本之间距离更远。

  • anchor是基准
  • positive是针对anchor的正样本，表示与anchor来自同一个人
  • negative是针对anchor的负样本

一组（anchor, positive, negative）构成一个triplet。一个triplet loss定义为：

L=max(d(a,p)+m−d(a,n),0)

最小化L的目标是：使得d(a,p)接近0，d(a,n)大于d(a,p)+m。

依据n和a的距离可以定义成三种类型的triplet：

不同的triplet对模型的效果影响可能会很大。FaceNet这篇论文，作者是为每一对anchor和positive随机选择一个semi-hard negative构建semi-hard triplet。

构造triplet的两种方式：Offline和Online

Offline：

在训练每个epoch的开始阶段，计算训练集种所有的embedding，并挑选出所有的hard triplets和semi-hard triplets，并在该epoch内训练这些triplets.

这种方式不是很高效，因为每个epoch都需要遍历整个数据集来生产triplets。

Online：

每个batch的输入，动态地计算有用的triplets。

batch all：挑选出所有合规的triplets，将hard triplets和semi-hard triplets的loss平均

batch hard: 对于每个anchor，挑选出hardest positive p（d(a,p) 距离最大）和hardest negative  n（d(a, n) 距离最小）。
