逻辑回归vs线性回归

逻辑回归虽然带有“回归”二字，但是实际是用来解决分类问题的。比如比赛赢还是输，逻辑回归分别输出1和0，逻辑回归算法的输出y∈{0,1}是个离散值，这是与线性回归的最大区别。

问题本质不同：

线性回归用于解决连续型输出的问题，而逻辑回归则用于解决二分类或多分类问题。线性回归的目标是预测一个连续值，因此使用最小化平方损失（MSE）作为成本函数是合理的。而逻辑回归的目标是估计某个样本属于某个类别的概率，输出是一个介于0和1之间的概率值。

输出形式不同：

线性回归的输出是连续值，而逻辑回归的输出是概率。线性回归使用的是连续值的预测与真实值之间的差异的平方作为成本函数，而逻辑回归需要一个能够衡量预测概率与实际类别之间差异的函数。

logistic函数

Logistic函数也称为Sigmoid函数：

f(x)=11+e−x

为何使用自然对数作为成本函数？

因为Sigmoid函数里有e的n次方运算，使用自然对数log刚好是其逆运算，这样模型参数的更新时不需要去计算复杂的对数运算和指数运算。成本函数形式如下：

cost(hθ(x),y)=−ylog⁡(hθ(x))−(1−y)log⁡(1−hθ(x))

上面是一个样本的成本函数，下面是多个样本的成本平均值：

J(θ)=−1m[∑i=1my(i)log⁡(hθ(xi))+(1−y(i))log⁡(1−hθ(xi))]

上面是二分类的成本函数，下面是多分类的成本函数：
