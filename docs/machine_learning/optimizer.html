局部最优问题、鞍点和海森矩阵

局部最优：梯度=0，进入局部最小值，并不是全局最小值

鞍点：梯度=0，既不是局部最小也不是局部最大值，在训练深度学习网络的时候，更多时候遇到的是鞍点，而不是局部最优问题

海森矩阵：一个多元函数的二阶偏导数构成的矩阵

当函数的海森矩阵在梯度=0位置的特征值全部>0，该函数得到局部最小值；

当函数的海森矩阵在梯度=0位置的特征值全部<0，该函数得到局部最大值；

当函数的海森矩阵在梯度=0位置的特征值有正有负时，该函数得到鞍点；

假设一个函数f，海森矩阵为：

A=(∂2f∂x2∂2f∂x∂y∂2f∂x∂z∂2f∂y∂x∂2f∂y2∂2f∂y∂z∂2f∂z∂x∂2f∂z∂y∂2f∂z2)=(200020002)

A 所有值为正，则令一阶导数=0，得到的解就是极小值点。

参数初始化策略和输入归一化策略

RMSprop

假设两个参数需要更新：w, b，将损失函数的梯度画在二维平面上，如下图所示：可以看到要走到中心红点，则需要竖直方向和水平方向都有所更新，其中水平方向的斜率小，竖直方向斜率大（想象）。

RMSprop的思路是给每一个方向x一个权重，使得竖直方向更新慢点，水平方向更新快点。具体做法是，利用梯度下降公式计算梯度更新时，乘上一个权重项，该权重项根据下图内Sdw和Sdb计算得到。比如b方向斜率大，那么希望更新慢点，需要×一个小点的数。

Adam

对更新的步长计算，能够从梯度均值及梯度平方两个角度进行自适应地调节，而不是直接由当前梯度决定
