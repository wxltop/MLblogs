集成学习

《百面机器学习》

集成算法（Ensemble）的思路是训练多个模型，将多个模型以一定的方式组合起来，降低预测误差。当需要预测一个新样本时，使用这些模型分别对这个样本预测，若是分类问题，采用投票法决定最后的类别预测；若是回归问题，取均值。

集成模型有3种常见集成策略，即bagging、stacking和boosting

集成学习的步骤如下：1. 找到误差相互独立的基分类器；2. 训练基分类器；3. 合并基分类器的结果（按照一定的策略组合起来，共同完成一个任务——特定的组合策略）。

基分类器

常用的基分类器是决策树，主要是因为决策树的表达能力和树的深度有关，以及决策树的性能受样本集的影响较大，随机性较大，这样不稳定的学习器更适合作为基分类器。除了决策树，神经网络模型也适合作为基分类器。

可否将随机森林中的基分类器，由决策树换为线性分类器或k-近邻？

随机森林属于Bagging类的集成学习，Bagging所采用的基分类器最好是不稳定的基分类器，但是线性分类器和K近邻都是较稳定的，方差不大，将他们作为基分类器不能在原有基分类器的基础上获得更好的表现。

Bagging

Bagging是Bootstrap Aggregating的缩写。核心思想是：采用有放回的采样规则，从m个样本的数据集进行n次采样（n ≤m），构成一个包含n个样本的新训练数据集来训练模型，上次过程进行B次，得到B个模型。对一个新样本，使用这些模型分别对这个样本预测，若是分类问题，采用投票法决定最后的类别预测；若是回归问题，取均值。

随机森林

随机森林属于Bagging类的集成学习

随机森林每次训练时，随机选择一个特征的子集来训练，该算法有两个参数：决策树的个数、构建单棵决策树特征的个数。

假设数据集有m个样本，n个特征。

单颗决策树构建：

  • 有放回采样，从原始数据集经过m采样，得到一个包含m个样本的数据集

  • 从n个特征里，使用无放回采样，从中取出f个特征作为输入特征

  • 在新数据集上（m个样本，f个特征）构建决策树

  • 重复上次过程t次，构造t棵决策树

综合多颗决策树的预测结果作为随机森林的预测结果。若是分类问题，采用投票法决定最后的类别预测；若是回归问题，取均值。

为什么随机森林要选取特征的子集来构建决策树？

假如某个输入特征对预测结果是强关联的，这个特征都会在所有决策树里体现，会造成所有的决策树都强烈地反映这个特征的，无法很好的解决过拟合的问题。这和使用正则项是一样的道理，使用正则项的目的是为了让每个特征都参与进来，而不是某一个特征起决定性作用，从而避免过拟合的问题。

Stacking

Stacking模型比bagging模型更进2步：(a)允许使用不同类型的模型作为base model；（b）使用一个机器学习模型把所有base model的输出汇总起来，形成最终的输出。（b）所述的模型被称为“元模型”。在训练的时候，base model们直接基于训练数据独立训练，而元模型会以它们的输出为输入数据、以训练数据的输出为输出数据进行训练。

Stacking模型认为，各个基础模型的能力不一，投票的时候不能给以相同的权重，而需要用一个“元模型”对各个基础模型的预测值进行加权

Boosting

算法原理是：初始时，有m个样本，给每个样本分配一个初始权重，然后使用这个带权重的数据集训练模型，训练完成后，增加预测错误的样本的权重值，然后拿出这个新的带权重的数据集来训练一个新模型，重复B次，得到B个模型。

所以训练Boosting是串联形式。这类模型的思想是，既然一个基础模型可以做出不完美的预测，那么我们可以用第二的基础模型，把“不完美的部分”补上。可以使用很多的基础模型，不断地对“不完美的部分”进行完善，以得到效果足够好的集成模型。Boosting的策略非常多，以GBDT为例，它会用第K个CART拟合前k-1个CART留下的残差，从而不断的缩小整个模型的误差。

和Bagging的不同？

  • 采样规则不同，Bagging采用有放回的采样，而boosting采用增加预测错误样本的权重的方法，相当于加强对错误预测的样本的学习力度，从而提高模型的准确性。

  • Bagging算法可以并行训练多个模型，但是Boosting只能串行训练，因为下一个模型依赖于上一个模型的预测结果。

Boosting和Adaboost的关系？

Boosting是思想，Adaboost是具体实现，继承了Boosting的思想，并为每个弱学习器赋予不同的权值，将所有弱学习器的权重和作为预测的结果，达到强学习器的效果。除了Adaboost，GBDT、XGBoost也属于Boosting。

CART

因为GBDT用到了CART，所以这里先介绍CART。

GBDT

GBDT是一种集成模型，采用的基础模型是CART回归树

GBDT的基本原理是使用梯度提升（Gradient Boosting）作为训练方法，

这里的“梯度”和“提升”没有直接关系：“梯度”被用来让损失函数快速下降，进而让模型效果“提升”。Gradient Boosting的基本思想是根据当前模型损失函数的负梯度信息来训练新加入的弱分类器，然后将训练好的弱分类器以累加的形式结合到现有的模型当中。

GBDT利用残差训练，在预测过程中，需要将所有树的预测值加起来，得到最终的预测结果。

推导：

假设GBDT里有N个CART，其中第K个记为Tk(x)，前k个CART的预测值记为：

fk(x)=∑i=1kTi(x)

GBDT是一种加法模型，它把所有基础模型的预测值累加起来作为最终的预测值。把前k个CART的预测值表示为一个递归形式：

fk(x)=fk−1(x)+Tk(x)

在训练第k个CART的时候，我们需要最小化这样一个目标函数：

J=∑n=1NL(yn,fk(xn))

更新模型：（注意这里的“模型”和平常的基于梯度下降更新的模型不同，这里是用函数空间来表示，不用参数化，后者用参数更新来表示模型更新）

fk(xn)=fk−1(xn)−α∗∂J∂fk−1

容易得到：

Tk(x)=−α∗∂J∂fk−1

表示的含义是：第k个CART的拟合对象为目标函数(对前k-1个CART输出值)的负梯度。设学习率α=1，因为是回归任务，使用平方和作为目标函数：

L=∑n−1NL(yn,fk(xn))=∑n=1N12(yn−fk(xn))2

因此有：

Tk(x)=−α∗∂J∂fk−1=−1∗∂J∂fk−1=yn−fk−1(xn)

意思是，GBDT的每一棵CART的任务，是拟合之前所有CART留下的残差。

这里总结一下：

  • GBDT由多个CART作为基分类器串联组成，每一个基分类器fk(x)的拟合目标是 真实值对前k-1个CART输出值的负梯度

  • 因为用的损失函数是均方误差（回归），所以负梯度可以化简为 真实值−fk−1(x)，即残差。

  • 从符号表示上看出来，每一个基分类器的输入都是x

  • 为什么叫梯度提升？第一个理解可以是：拟合梯度，提升模型效果。第二个理解可以是：希望残差即负梯度越来越小，取反即梯度越来越大。

  • 在预测阶段，每个CART是独立的，因此可以并行计算。

  • 在训练阶段，GBDT里的CART之间存在依赖，无法并行，所以GBDT的训练速度是比较慢的。
